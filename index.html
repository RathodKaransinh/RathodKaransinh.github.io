The system

How the pieces fit together

Three platforms sit on a shared data layer I also own. Market prices, standardised financials and corporate filings flow in on a schedule; research flows out as recommendations — and those recommendations loop back into execution.

What I own

Three platforms, end to end

Architecture, core functionality, data layer and day-to-day operations — used across the research, investment and operations desks of a SEBI-registered asset manager.

RAW

Research Automation Works

~40 analysts & IC
  • Core research workspace on Django REST + React/TypeScript: research notes, quarterly results, financial statements, CIO decisions and company coverage across a ~2,600-company universe.
  • Analyst Portfolio Simulator — replays each analyst's recommendations as real order executions against the firm's portfolio, then scores performance with the same analytics used for live funds. Research calls become measurable instead of anecdotal.
  • Role-based access with row-level security by country, sector and company; real-time collaborative comments over Django Channels WebSockets.
  • Automated intake through 32 scheduled jobs and 20+ scrapers: corporate announcements and actions, BSE insider trades, G-Sec yields, and management interviews transcribed with Whisper and summarised by Gemini.
RAW AI

Retrieval assistant over the research corpus

RAG · Claude · Gemini
  • RAG over proprietary research and public filings: concalls, annual reports and investor presentations parsed with Document AI and LlamaParse, chunked, embedded into pgvector, reranked, and answered with citations back to the source document.
  • Result Update Report pipeline — drafts an analyst's quarterly result update from a company's concall transcript, investor presentation and earnings report PDF. A finely-grained section-wise prompt produces topline, margin, bottomline and segment performance, plus actuals versus management guidance, each section grounded in the source documents.
OAT

Operation Automation Toolkit

~15 ops & portfolio staff
  • Order engine — buy/sell/ETF calculators with T+1 cash and settlement logic, percentage-of-volume allocation and contract-note processing. Custodian order files are generated, validated and delivered automatically.
  • Trade Suggestions — merges analyst recommendations raised in RAW with live portfolio positions to compute actionable trades, closing the loop from research call to execution.
  • Portfolio analytics — XIRR/TWRR performance and benchmark reporting, management-fee billing, custody and fund-accountant reconciliation across PMS, AIF and GIFT-City IFSC mandates.
  • Integrations with Zerodha Kite, Interactive Brokers, Nuvama and Zoho CRM; an operations-checklist engine running 10 automated checks with Google Chat alerts; natural-language portfolio Q&A via text-to-SQL, guarded by a SQL validator.

Underneath

Data infrastructure & tooling

The shared layer all three platforms depend on, plus the CI tooling that keeps them honest.

Market Data Pipeline

Python · Cloud Run · KiteConnect · IBKR · PostgreSQL

  • Broker adapters that normalise two very different market-data sources behind one interface — KiteConnect for Indian listed equities, IBKR for international coverage — writing live and historical prices into PostgreSQL.
  • 7 Cloud Run jobs covering daily, intraday and VWAP prices, IBKR prices and USD/INR rates, plus a shared Python library installed into all three platforms as their single market-data access layer.
  • Retired a dedicated always-on VM that held an 8.5-hour websocket connection, replacing it with scheduled quote pulls.
    − one standing point of failure, − its compute bill

Financial Data Pipeline

Python · ACE Equity · PostgreSQL · Cloud Scheduler

  • The firm's fundamental data store: quarterly and annual results and full financial statements loaded into PostgreSQL through the ACE Equity Excel plugin rather than a vendor data API.
  • Gives RAW and OAT direct SQL access to standardised financials for screening, valuation and analysis.
    saves lakhs per annum in vendor API licensing

Claude PR Review Bot

Python · Docker · Claude API · Bitbucket Pipes

  • A reusable Bitbucket Pipe that reviews every pull request in two stages: it first explores the repository with tools, then returns a structured assessment as inline PR comments.
  • Each repository's CLAUDE.md acts as its review rulebook. Versioned, tested, and running in CI across 5 production repositories.
